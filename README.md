# Tanita MC-580 über Web Bluetooth

Eine statische Seite, die eine Körperanalysewaage Tanita MC-580 per Web Bluetooth ausliest: auf dem iPad im Browser Bluefy, am PC in Edge oder Chrome.

Aufruf: https://schroering-abke-cmd.github.io/tanita-web/

Die Seite schickt keine Daten an einen Server. Personen und Messungen bleiben im Browser des Geräts, eine CSV lässt sich herunterladen bzw. teilen. Dieses Repository enthält nur die Seite, keine Messwerte. Entwickelt wird sie im privaten Repository (`Tanita-MC580/web/index.html`).
